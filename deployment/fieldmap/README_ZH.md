# 原地环境观察与网页复核

观察台已并入既有 **XLeRobot Studio 8770平台**。打开 `http://192.168.137.150:8770/`，点击左侧“空间观察”；直达地址为 `http://192.168.137.150:8770/#fieldmap`。页面保留平台主导航和状态区，接口、照片与静态资源均由同一个Studio进程承载，全部资源本地提供。

随现有Studio启动，无需额外服务：

```powershell

```

后端`integration.py`注册 `/api/platform/fieldmap/*`、`/fieldmap/images/*`、`/fieldmap/assets/*`，`/fieldmap/view`仅作为平台内部视图；`/fieldmap/`返回主平台的空间观察页。地图加载、人工复核、导出和停止请求沿用平台来源检查。没有新增站点、监听端口或开机任务。

已部署机器继续使用 `D:\Robot\FieldMap`，通过车载私有`.local-deploy/studio-network.json`的`fieldmap_data_dir`设置绝对路径；也支持`XLEROBOT_FIELDMAP_DATA`。未配置时默认使用平台数据目录下的`fieldmap/`。迁移时保留数据，停止并禁用旧`XLeRobot-FieldMap`任务、关闭8782规则与监听。原独立服务和注册脚本已从源码移除。

旧版观察台只需迁移一次。先部署本模块及平台更新，再在笔记本运行：

```powershell
.\deployment\fieldmap\migrate-to-studio.ps1 -Repo D:\Robot\XLeRobot -DataDir D:\Robot\FieldMap
```

迁移脚本在无接管、动作或录制时只重启Studio，核对控制进程未变以及地图、照片、复核文件哈希，最后停用旧入口。配置和旧启动文件保存在运行目录的私有`.local-deploy/fieldmap-studio-<时间>/`，以供恢复。

实际数据保存在 `D:\Robot\FieldMap`，不进入源码 Git。`map.json` 包含 observation 视角、照片路径、拍摄时刻、关节及轮组读数、feature 语义对象、示意平面轮廓和照片上的归一化多边形。照片放 `images/`，只开放地图明确引用的文件；`reviews.json` 按地图ID保存人工分类、备注和修改历史。运行日志、临时图、认证信息均不提交。

页面提供平面/立体示意切换、分类图层、照片依据与叠加轮廓、逐条现场复核、数据导出、实时电机与轮组状态，以及停止请求。立体高度和物品轮廓是为了表达空间关系的示意，不能作为测量。当前RGB图片没有相机内外参、深度和可靠轮地里程计，地图必须明确标记为相对方位示意；未观察区域为未知，画面上看起来有地面只能标“候选可走”。办公椅脚伸出、车宽与手臂扫掠、桌下线缆、跌落边缘尚未验证时，不能写为可通行。人工复核保存不开放行驶权限，服务没有驱动/导航接口。

相机采集先经8765唯一硬件所有者的 `agent/run` 顺序执行；不要另外打开串口或同一UVC设备。先确认没有其他接管、助手运行、限位自检和录制。本次原地旋转由用户明确授权；`rotate` 步骤仅接受方向、40–650ms时间和60–160速度上限，始终平移速度为零。每次写非零前创建本地到期定时器；结束时双轮写零、关闭轮组驱动力，并用200ms编码器稳定窗口确认停稳；双臂仍保持。输入、取消、通信错误或不对称轮位移使运行中断，不自动续跑。手柄连接不是本次扫描的前置条件，有输入时沿用现有停止规则。

本地定时器与停止回读已覆盖正常异常路径，但定时器位于控制进程内，不能保证整个串口所有者被强杀、系统冻结或板端通信断开后仍能停车。本阶段只支持有人监督、逐次观察的短脉冲；完整无人移动仍需独立于控制进程的停车监督或板端命令有效期，并另行做故障注入实测。

2026-11-02用户随后明确授权向过道谨慎慢移、以建图为主。助手本机接口增加`advance`：每次只能提交一个前进脉冲（40–650ms、60–120原始轮速），其后只允许拍照；不接受转向、倒车或连续推进计划。需引用最近一次成功观察运行，含60秒内的头部及至少一路低处相机、拍照时轮位；确认姿态与轮位未改变后，助手逐图判断短行程净空，再提交下一次。依据只使用一次；过期、姿态变化、停车失败、轮位不对称、通信错误或手柄输入均中断，不自动重放。时间与原始轮速不等于实测米数或地面速度。

本轮有效短移5次，随后因行人穿越及近处椅子变化停止深入；首次180ms脉冲没有有效轮转、另一次照片过期未发车。新增37张照片和6项标记，主平台现有68图/23项。之后检测到手柄重连和新的本地控制/轮位变化，助手让出控制，地图标为历史观察、当前位置需重新定位。本轮未到达开阔过道，没有连续定位、实时人员跟踪或完整自动避障；`motion_enabled=false`继续表示网页没有开放行驶控制，并不否定对话中已授权的受限短移。
