# 原地环境观察与网页复核

网页部署在车载笔记本，默认入口 `http://192.168.137.150:8782/`，本机也可用 `http://127.0.0.1:8782/`。全部静态资源随工程提供，不依赖 CDN 或工作电脑的网页服务。

在车载运行目录执行：

```powershell
.\deployment\fieldmap\start-fieldmap.ps1
```

`XLeRobot-FieldMap` 开机任务可调用同一脚本；首次发布时只放行现有工作端到8782，不对公网开放。更换接入网络后按实际局域网调整防火墙范围。

管理员运行 `deployment/fieldmap/register-fieldmap.ps1` 注册开机任务及精确客户端防火墙规则。它保留现有Python入站阻断的其他端口，只为8782开一个受限入口；修改前在数据目录留备份。任务允许电池运行，进程失败一分钟后重启，不重放动作。

实际数据保存在 `D:\Robot\FieldMap`，不进入源码 Git。`map.json` 包含 observation 视角、照片路径、拍摄时刻、关节及轮组读数、feature 语义对象、示意平面轮廓和照片上的归一化多边形。照片放 `images/`，只开放地图明确引用的文件；`reviews.json` 按地图ID保存人工分类、备注和修改历史。运行日志、临时图、认证信息均不提交。

页面提供平面/立体示意切换、分类图层、照片依据与叠加轮廓、逐条现场复核、数据导出、实时电机与轮组状态，以及停止请求。立体高度和物品轮廓是为了表达空间关系的示意，不能作为测量。当前RGB图片没有相机内外参、深度和可靠轮地里程计，地图必须明确标记为相对方位示意；未观察区域为未知，画面上看起来有地面只能标“候选可走”。办公椅脚伸出、车宽与手臂扫掠、桌下线缆、跌落边缘尚未验证时，不能写为可通行。人工复核保存不开放行驶权限，服务没有驱动/导航接口。

相机采集先经8765唯一硬件所有者的 `agent/run` 顺序执行；不要另外打开串口或同一UVC设备。先确认没有其他接管、助手运行、限位自检和录制。本次原地旋转由用户明确授权；`rotate` 步骤仅接受方向、40–650ms时间和60–160速度上限，始终平移速度为零。每次写非零前创建本地到期定时器；结束时双轮写零、关闭轮组驱动力，并用200ms编码器稳定窗口确认停稳；双臂仍保持。输入、取消、通信错误或不对称轮位移使运行中断，不自动续跑。手柄连接不是本次扫描的前置条件，有输入时沿用现有停止规则。

本地定时器与停止回读已覆盖正常异常路径，但定时器位于控制进程内，不能保证整个串口所有者被强杀、系统冻结或板端通信断开后仍能停车。本阶段仅允许有人监督的原地观察；完整无人移动仍需独立于控制进程的停车监督或板端命令有效期，并另行做故障注入实测。
