键盘与按钮操作

先观察现场、确认周围安全，再开启控制。所有动作按住才运行；打开视频不会开启运动控制。

  • 方向键驾驶；1 / 2 / 3 选择左臂、右臂或双臂。
  • W / S 升降，A / D 伸缩；Q / E 肩转，R / F 腕俯仰，Z / C 腕转。
  • U / O 夹爪开合；I J K L 控制头部。
  • 逐关节模式选中关节后用 [ / ]，或按住对应 ± 按钮。
  • Shift 临时精细速度；空格或 Esc 停止。离开页面或失焦会结束控制。
