QUICK REFERENCE

记住这几件事。

  1. 主动开启先观察现场，再开启控制。浏览页面不会发动作。
  2. 按住才动松手保持当前位置；夹爪松键后保持，不自动张开。
  3. 随时停止空格或 Esc 结束控制。切页、失焦、断网也会停止。
  4. 精细一点Shift 降速。参考不足或姿态折叠时，改用逐关节调整。
