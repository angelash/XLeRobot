# 限位自检

控制页“限位自检”用低速、低扭矩把关节推到机械止挡，记录真实限位并写入舵机。适合手动采集没转满、或怀疑关节之间有干涉的情况。

## 用法

1. 结束手柄接管，手柄放下并回中。手柄在线时，自检中按任意键或动摇杆会立即停止；手柄休眠或断开不阻止自检，此时用页面“立即停止”。
2. 打开“限位自检”。面板已按一条龙推荐方案勾好全部16项：头部俯仰、头部水平，然后每条臂依次为夹爪、腕旋转、腕俯仰、肘、肩抬升、收起此臂、肩水平。可以自由增减勾选，执行顺序固定为推荐顺序。
3. 勾选现场确认，点“开始自检”。卡片实时显示当前关节、方向、位置、目标和负载；“立即停止”随时可用。

## 每个关节怎么测

- 先把会干涉的关节摆到行程中位：测腕俯仰前肘放中位，测肘前腕俯仰放中位，测肩抬升前肘和腕俯仰放中位。测完全部回到原姿态。
- 竖直起点（推荐）：在“竖直此臂”卡片记录该臂竖直向上时的肩抬升、肘、腕俯仰读数（用“手动摆位”卸力扶直后锁定再点记录；按电路板保存在\`.local-deploy/upright-poses.json\`，舵机零点变化后自动作废）。记录后，该臂的腕俯仰、肘先摆到竖直再测，两个方向都是向下摆离车体；测肩抬升时上臂竖直、肘放中位，收短手臂、减小力矩，也避免扫到放在车前的笔记本。该臂最后一项测完再回到测试前的姿态（后面有“收起此臂”时由收起负责）。“竖直此臂”也可以单独勾选，只把手臂摆到竖直。2026-10-30实测：左臂（COM4）竖直约为肩抬升2211、肘952、腕俯仰2242，右臂（COM3）约为2245、901、2049；判断依据是笔记本摄像头正面画面和三个关节负载均降到0–3%。
- 预置只为让出空间：若被姿态干涉挡住（实测左臂收起时肘展开到约2150即被车体挡住），关节停在受阻处，主测关节照常探测。
- 降低扭矩上限（夹爪/腕/头约35%–45%，肘、肩抬升最高75%；预置、回位和收起在已知行程内移动，用全扭矩，回起点至少20°/s），以10°–25°/s推进目标。目标领先实际位置超过阈值且0.4秒内几乎不动，即判为顶到止挡：立即把目标设回实际位置卸力，再退回约3°。2026-10-30实测肘60%、肩抬升80%在托举前臂/整臂时力量不足。
- 过载保护：舵机出厂设置为负载超过80%（寄存器36）持续2秒（寄存器35）后输出降到20%（寄存器34）。2026-10-30 17:08一轮中，右肘（峰值85%）、右肩抬升（79%）等4项顶到止挡后都退不回来。现在探测扭矩取“过载阈值−5%”与原设定的较小值；退离止挡必须真的移动至少一半距离，退不动或回位受阻时记录舵机状态（含“过载”标志）、负载、电压和温度，等待2.5秒再试，最多3次。
- 已存行程外最多再探30°–60°；腕旋转通常没有硬止挡、以线缆为限，到探测上限即停。
- 新限位为止挡位置内缩约2°。若在已保存（手动转到过）的行程内就受阻，判为姿态干涉或扭矩不足，那一端保留原限位、不收窄。
- 肩水平必须在该臂全收起时测：方案中的“收起此臂”会把肩抬升、肘、腕俯仰同步移回保存行程时的折叠姿态；没有该记录时只能手动收起。
- 勾选“测完自动写入新限位”时，限位在扭矩保持下写入并逐颗回读，同时更新已保存行程，下次采集自动带入。中途停止的关节不会留下未探测的临时范围：只放宽到包住当前停下的位置。

## 边界

止挡判断依赖编码器跟随与负载，低扭矩下仍会接触机械结构；不包含碰撞规划，也不判断线缆是否被拉紧。腕旋转等无硬止挡的轴，结果代表“探测范围”而非机械极限。结果文件保存在当天证据目录的`limit-selftest/`，不提交Git。
