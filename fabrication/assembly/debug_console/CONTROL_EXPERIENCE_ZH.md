# 控制反馈体验设计 · 2026-10-28

目标：用户不翻代码就知道“按什么、控制哪个、为什么没动、接下来做什么”。当前控制能力是单关节低速小步，不能让视觉暗示摇杆已支持整臂或底盘遥控。

## 信息层级

1. 顶部常驻接管条：接管未开启 / 接管已开启 / 接管保留且故障暂停。启动、结束、恢复是独立动作，文字同时说明是否会改变扭矩。
2. 主操作区：左侧手柄图，按键亮起与真实原生输入同步；右侧当前关节、实际值、目标值、允许范围、正反向剩余量和最近一次执行结果。图上点按是查看说明，不模拟按键也不移动机器人。
3. 映射说明：简明模式优先显示LB、十字键、B、View；完整模式包含所有标准按钮、双摇杆、扳机、系统键与Elite背键的能力边界。每项包含操作方法、控制对象、条件、预期结果、当前实时状态。
4. 选择关节：用具名关节卡代替只显示COM/ID的下拉框；保留精细设置。标明行程过窄的不可用关节，点击可查看原因，不猜测扩大限位。
5. 执行反馈：输入已收到 → 条件检查 → 目标已发送 → 编码器反馈。被拒绝显示原因；写目标不代表已移动，位置变化不代表精确达到目标。
6. 视频、硬件表与完整日志放在下方，可展开。日志默认显示用户能读懂的事件，可按输入/动作/边界/故障筛选，原始字段在详情中展开，刷新保留已展开项。

## 接管与动作状态

- 接管属于用户：只有用户点击结束或按View才主动结束。服务进程退出不能保留内存会话，重启后需要重新启动；不跨重启自动运动。
- LB是瞬时动作许可：松开即停止本次动作并保持，接管不取消。B同样只停止本次动作，必须松开再按LB才能继续。
- 到达范围边界、重复方向键、上一条指令等待反馈：提示本次没有发出或只能走剩余小步，接管和参数保持。反向或选择其他关节可继续。
- 手柄掉线、输入超时、网页心跳丢失、通信错误、温度/供电异常、无编码器反馈：暂停动作，接管保留。显示具体原因和恢复步骤，用户确认恢复且LB/B/方向键松开后才允许新的指令。恢复不会续发旧目标。
- 新接管、故障恢复均要求先松开LB；防止把旧的按住状态当作新使能。
- 关闭扭矩与停止动作明确分开；停止接管、故障暂停均不主动释放手臂支撑。扭矩开关保留于精细设置。

## 映射策略

硬件映射来自服务端 `control_mapping.py`，页面引用同一份说明。

- LB + 十字键上下：当前关节正/反向一步。正反指编码器增加/减少，未经物理确认不写“抬起/放下”。
- LB + 十字键左右：上/下一个可用关节；页面可直接选择，选择本身不向新关节发送移动。
- B：停止本次动作、接管保留；View：用户主动结束接管。
- A：展开当前关节说明；Y：简明/完整切换；Menu：定位完整映射。这三项只操作网页。
- X、RB、摇杆按下：未绑定运动，记录与可视化；双摇杆及LT/RT只观测输入。
- Xbox系统键与Elite独立背键身份不可由标准XInput读取，明确标识；背键映射为主键时显示对应主键。

## 反馈与设置

- 短按使用原生事件边沿处理，避免HTTP轮询漏掉快速点按；按键保留约900ms的“刚按过”反馈，实时按住与最近按过分开显示。A/Y/Menu同样消费原生事件，不将历史日志重放为页面动作。
- 每次指令固定显示关节名、目标、实测值、误差、时间与结果；原始日志可以导出。
- 边界提示使用琥珀色，故障暂停使用红色，收到输入和验证到位使用不同层级。信息不只靠颜色表达。
- 不自动放大限位，不自动循环执行，不把按住方向键改成连续运动。
- 简化设置提供4/16/32计数（约0.35°/1.4°/2.8°）预设；精细设置保留单步与速度。参数修改要求LB松开。
- 暗示效应控制：未连接手柄时所有键显示“未连接”，而非“松开”；系统键显示“不提供”；没有实际编码器反馈不亮“完成”。

## 验收

- 边界后仍online且可反向；松LB/B不结束接管；断连/心跳失效变为paused而非offline；恢复必须是新LB边沿。
- 页面按键与映射、当前关节和日志一致；模拟按键展示不触发HTTP运动接口。
- 桌面检查布局；窄屏使用单列，控制对象提前。部署前若用户正在接管，不为刷新代码擅自中断该会话。

## 本轮验证结果

- 18项离线行为/API测试通过：包含限位保持与反向、缩短步长提示、B停动作后重新使能、斜向输入不动作、未绑定按钮不移动、断连/输入/页面超时暂停保留接管、手动恢复不重放、保持失败恢复前重试、View主动结束。
- Node使用真实HTML ID及服务端22项映射验证页面，检查简明/完整、图示点击不发硬件命令、LB高亮、限位/暂停状态、恢复门控、短按UI快捷键、目标与实测、过期输入与日志筛选。
- 实际浏览器核验桌面页面、完整映射、按键说明及实时16电机数据；本轮不冒称完成实体手柄按键或新实机运动验收。
- 窄屏媒体查询已实现；本轮未做真实手机/窄视口浏览器验收。
