## 阶段 3：退离实验（左腕俯仰，下端止挡约 950）

每次先探到止挡，再按不同方式退离，同时以约 55 Hz 记录。“往回”指离开止挡的方向；之前的算法不分方向，曾把往里多压当成开始移动，已修正。

| 方式 | 从发出退离到开始往回 | 说明 |
|---|---|---|
| 立刻退（3 次） | 约 0.94–1.0 s | 先往里多压 6–9 个计数，负载约 1 秒内从 45%–72% 降到 0 后才往回 |
| 等 0.5 / 1 / 2 秒再退 | 0.47 / 约 0.1–0.27 / 约 0.06–0.19 s | 等待加延迟合计约 1 秒 |
| 先松 5 个计数 | 0.59 s（另加 0.3 s 等待） | 合计约 0.9 秒 |
| 扭矩上限降到 0 约 0.2 秒 | 约 0.8 s | 恢复后仍往里压，没有帮助 |
| 等负载回落 < 10% 再退（修复后，2 次） | 0.08 / 0.20 s | 回落用时 875 / 938 ms，没有往里多压 |

舵机状态寄存器始终是 0x00，扭矩上限 100%。舵机的速度环积分系数（寄存器 39）是 200，位置环积分（23）是 0。由此推断，原因是速度环积分饱和；这是推断，不是厂家资料。正式自检原来判断“退不出来”的时限约 0.85 秒，比这 1 秒短，所以第一次总被误判为卡住。修复后，自检和助手运行都改为先等负载回落再退。
