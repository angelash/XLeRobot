# 网页键盘与按钮遥控

入口：原 XLeRobot Studio 的 **键盘遥控**，车载地址 `http://192.168.137.150:8770/#teleop`。控制中心、总览和能力目录均可进入。仍使用同一8770应用与8765唯一串口所有者。

先观察实际运动范围，勾选现场确认，再点“开启网页控制”。开启只保持实际当前位置、准备可用设备，不归零。无需连接实体手柄。所有动作按住才运行，松键保持；夹爪松键保持原开度，不会自动张开。

## 按键与界面

- 方向键：↑前进、↓后退、←左转、→右转；可同时前进和转向。沿用本机已验证的原版方向及用户方向设置；双轮不支持横移。
- `1 / 2 / 3`：物理左臂、物理右臂、双臂。左右绑定来自现有控制板映射。
- 简易联动 `W / S`：末端升高／降低；`A / D`：收近／伸远。联动肩抬升、肘、腕俯仰，维持当前腕俯仰总角。需要匹配当前设备限位与零点的已验证参考，并通过当前姿态IK往返检查。
- `Q / E`：肩水平负／正向；`R / F`：腕俯仰负／正向；`Z / C`：腕旋转负／正向。方向沿用逐轴设置。
- `U / O`：夹爪张开／闭合，使用已确认的开合端点判断原始值方向；无参考时可用第6关节正负向调整。
- `I / K`：抬头／低头；`J / L`：向左／向右看。
- 逐关节模式：6个关节分别提供按住运行的 `− / +` 按钮；选中关节后可按 `[ / ]`。显示实际编码器和当前设备限位，双臂模式显示两侧数值。
- `Shift`：临时20%精细速度；速度条20%–100%，默认50%。网页单轴最高12°/s、夹爪100raw/s，并受现有逐轴设置约束；双轮最大160raw。
- 空格、`Esc`或“立即停止”：结束控制，双轮归零、运动关节保持当前位置；再次运动须重新开启。

每项键盘动作有对应屏幕按钮，支持鼠标和触屏指针捕获。切换手臂、模式、关节或速度时先清空按键。输入框、选择框或可编辑内容获得焦点时清空动作，不消费其文字输入。

## 会话与保护

网页独立会话使用随机令牌及递增序号，输入每100ms更新，650ms租约只由此会话的新输入续期。过期后失效；旧输入、旧停止请求和其他页面的状态轮询不能接管或延长动作。公开遥测不返回令牌。请求锁等待与串口操作可能增加实际停车响应时间，650ms不是硬实时保证。

松键立即发送完整中性输入；切页、后台、窗口失焦、关闭页面或遥测失效均请求结束会话。断线时控制端独立看门狗兜底，不重放旧键。实体手柄任意有效输入结束网页会话，之后可另按Menu启用手柄；网页不会代用户开启手柄接管。

手柄接管、助手运行、自检、手动标定、摆位与抓取互斥；Studio正在录制时阻挡开启。使用现有限位、维护隔离、逐轴方向和跟随约束，不修改ID、模式、PID、零点或固件。温度疑值按同电机最多3份新包确认；持续供电、温度、模式、扭矩、通信或编码器受阻异常结束会话。轮子约0.8秒窗口未按命令方向转动即停，不能把此保护当作碰撞检测或自动避障。

底盘由人结合现场／相机判断净空；相机区按需通过原快照接口读取头部／双腕新帧，页面不提供全机碰撞规划。末端坐标是现有二连杆模型量，不能当物理测量；肩转和腕姿按钮是相对关节调整，简易联动不是自动抓取。

## 验证范围

自动检查使用生成输入及假STS总线，覆盖启动保持、限位、方向、租约、乱序、手柄抢占、受阻停止和接口校验。浏览器交互在隔离假控制器上验收；部署后只读核对网页与路由。软件验证不替代真实运动、物理方向、弱网或全身碰撞试验。
