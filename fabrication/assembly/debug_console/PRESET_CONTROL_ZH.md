# 预设直控与逐轴调节

这是硬件和接线已枚举、但精确参考姿态尚未完成时的显式试运行入口。它按项目原版开源手柄映射直接测试相对关节轴，使用当前真实设备范围和模式，不伪造运动学零位。适合先发现左右反向、装配干涉、响应不足、速度和跟随问题，再决定是否进入精确联动。

## 启动顺序

1. 在Studio控制页选择“预设直控 · 开源映射试运行”，勾选确认并让手柄全部回中。
2. 启动仍会完整扫描16电机、检查模式/电压/温度并保持当前位置；双轮保持零速。
3. 双杆直接测试对应臂的肩抬升/肘；LS/RS切换肩水平，LB/RB切换腕姿；扳机测试夹爪；ABXY测试头部；方向键测试底盘。
4. 在“控制设置”中修改逻辑左右臂/轮映射和逐轴方向、速度、跟随容差；保存后下一次动作生效。

预设模式是开环调试手段：它不证明末端IK精度、碰撞安全、夹爪几何或轮里程。精确联动仍需另选“整机实机 · 完整手柄映射”，该入口保留A/B/C实测参考要求。

## 已知边界

用户现场确认两臂交叉安装但保留装配，因此逻辑映射可互换，不改物理电机ID和配置。2026-10-29完成预设控制与逐轴参数实现和164项离线回归，但没有在新代码下完成现场电机动作验收。首次接回设备时仍需确认USB身份、16颗在线、手柄回中、T=0与设备范围/模式匹配；双轮落地短测与停车按现场空位确认。
