# 预设直控：先试动，再逐轴调

预设直控是控制页的默认模式（整机联动未就绪时）。它按项目原版 Xbox 手柄布局，把每个摇杆轴直接接到一个关节，在舵机已保存的限位内持续转动；不需要先录 A/B/C 姿态卡，也不伪造运动学零位。先用它发现方向反了、速度不合适、装配干涉、某个关节不响应等问题，再按需进入“整机联动 · 末端IK”。

## 第一次用（接回设备后）

1. 打开 `http://笔记本IP:8770/runtime/original`，控制目标默认就是“预设直控”。
2. 上方“直控范围：N/14”显示有多少关节已使用实测行程。没保存过行程的关节只能在旧试控窗口（约±2.8°）里动，右侧部件状态会标黄“范围很小”，并给出“去保存行程”入口。
3. 放开行程：点“打开采集” → 勾选支撑 → “备份并关闭扭矩，开始采集”。一次转一个关节走过要用的范围再回中，表格里≥48计数即有效。随时点“保存已采行程 · 开放直控”：逐颗写入舵机限位并回读，失败整批回滚、已录内容保留；成功后采集自动结束、扭矩保持关闭。不需要姿态卡。
4. 手柄回中，勾选确认，点“开启预设直控”。开启时保持当前位置，不归零；能用的部件立即接入，个别不能用的部件只列出原因，不影响其他部件。

## 手柄映射

- 左杆左右＝左肩抬升，前后＝左肘；按住 LB 再拨＝左腕（左右旋转、前后俯仰）；按住 LS 左右＝左肩水平；LT 压下闭合左夹爪、松开张开（首次压过75%后接入）。右侧同理。

### 用 Elite 背键转肩水平（手臂底座旋转）

按住摇杆的同时再拨它不顺手，Elite Series 2 可以把背键映射成“摇杆按下”。映射后，按住背键再左右拨同侧摇杆，就是转同侧肩水平，控制程序不需要任何改动：

1. 在任意一台 Windows 电脑上从 Microsoft Store 安装“Xbox 配件”（Xbox Accessories），用 USB-C 线或无线接收器连上手柄。
2. 进入手柄“配置”，新建配置文件：左上背键 P3 映射为“左摇杆按下”，右上背键 P1 映射为“右摇杆按下”（下方 P4/P2 可同样设置，或留空）。
3. 把这个配置保存到手柄上的一个配置槽，并用手柄中间的配置键切到这个槽。配置存在手柄里，接回车载笔记本后照样生效。

控制页“按键用途与实时输入”里的“LS按住 / Elite背键”一栏会在按下背键时显示“按下”，可用来确认映射是否成功。

背键不能直接读取的原因：XInput 不包含背键；Windows.Gaming.Input 虽有 Paddle1–4，但只把输入交给前台窗口。2026-10-30 在车载笔记本的开机服务（无登录、session 0）里实测，该接口能识别到手柄（PID 0B00），读数时间戳始终为 0，收不到输入。

## 手动摆位：卸力、用手摆、再锁定

控制页“整机初始化”下方的“手动摆位”面板不需要开启接管：

- 按左臂、右臂、头部、底盘轮分组，每个电机一个按钮，显示“锁定”或“已卸力”；也可以“全部卸力”。手臂受重力的关节要点两次，第一次提示先托住手臂；头部、夹爪、腕旋转和底盘轮点一次即生效。
- 摆好后点“锁定当前位置”：读取当前位置作为目标再打开扭矩，不会跳动。被手推出原限位的关节先把限位放宽到刚好包住当前位置（多留 8 计数），同步更新已保存行程，并在消息和日志里列出新范围。
- 手柄接管中点任一按钮会先结束接管再执行；限位自检进行中不能操作；采集中扭矩本来就是全关的，可直接用手摆，结束采集后再锁定。
- X/B 头部水平，A/Y 头部俯仰。
- 十字键 ↑ 前进、↓ 后退、← 左转、→ 右转；行驶时 LB 减速、RB 加速。沿用上游 `get_base_action`（↑ 发 `k`），2026-10-30 实测本机 ↑ 即前进；方向不符时在控制设置切换。
- Menu 暂停（回中后页面恢复），View 结束接管。

## 边动边调

“控制设置”可以在接管中修改，保存后下一次拨杆就按新值执行，不需要结束接管：

- 关节默认速度（1–90°/s）、夹爪速度（20–800 raw/s）、底盘速度上限（100–3000 raw/s）、目标跟随窗口（16–512 raw）。
- 逐轴：每个关节和两个头部轴的方向（按手柄正向/反向）、速度、容差。留空即使用默认值；只有改过的轴会保存成覆盖值，之后调默认速度仍对其余轴生效。夹爪一行的速度单位是 raw/s。
- 左右臂逻辑对调、底盘“前进方向”和“转向方向”需要先结束接管再改。前进方向只翻转前进/后退，转向方向只翻转左/右转，两个开关互不牵连。

## 出问题时

- 多个电机同时加速时供电读数会瞬间下跌：单次偏低不算故障，连续3次才暂停该关节，约1秒后自动重试，其余部件不受影响。模式/扭矩类异常同样只暂停该关节并自动重试；串口通信故障才暂停整机。
- 关节被挡住（编码器不跟随目标）时只停住这一个关节并提示“在某位置受阻”，整机不暂停，可直接反向；夹爪夹住物体时保持轻夹。受阻位置会记录下来作为限位参考。
- 按 Menu 暂停，再按一次 Menu 继续；手柄短暂断开后重新连接并回中即自动继续，不重放旧输入。网页关闭或在后台只提示，不影响手柄控制。
- “目标跟随滞后”说明舵机跟不上：调低该轴速度或加大容差。到舵机限位会自动停住并提示，可反向；夹爪停在张开端是正常释放状态。
- 想拿到真实机械限位，用控制页的“限位自检”，见 [LIMIT_SELFTEST_ZH.md](LIMIT_SELFTEST_ZH.md)。

## 边界

预设直控是开环的逐关节控制：它不证明末端 IK 精度、碰撞安全、夹爪几何或轮式里程。底盘轮径 127mm、轮距 250mm 为资料值，不是实测。整机联动仍需要在采集面板录齐双臂 A/B/C 与夹爪端点并“保存完整标定”。截至 2026-10-29 晚，这一版只在本机假总线和浏览器里验证，尚未在接回的实机上做动作验收。
