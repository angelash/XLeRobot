# XLeRobot 0.4 双轮首次上电操作清单

日期基线：2026-10-27。当前只读复核结果：COM3=ID 1–8，COM4=ID 1–6、9、10，共 16 个电机；电压约 12.1–12.4V；三路相机可枚举；Xbox Elite 2 已识别。以上只证明通信和枚举，尚不能证明物理对应、校准、方向、停车和安全边界正确。

开始前固定以下定义：站在推车后方，与机器人前进方向相同；你的左手边是机器人左臂，右手边是右臂。给实际部件贴 L/R、臂/头、轮 9/轮 10、CAM01/02/03 标签。

## 第一项：确认左右臂与关节

### 准备

1. 打开 http://127.0.0.1:8765 ，确认安全状态为“停用”，两块板显示扭矩 OFF。
2. 用支架、泡沫或请人托住机械臂。手臂断电时可能受重力下落，不能让它悬空受撞。
3. 不运行 LeRobot 机器人程序，不点 Bambot 的位置控制或“启用扭矩”，也不重跑 `setup_motors`。
4. 每完成一行，就停止、确认数字再移到下一个关节；不要同时扭两个关节。

### 操作

手动缓慢移动一个关节，观察页面哪个 `COM` 的哪个 `ID` 的位置数值变化。若数值不动，先确认该臂是否在该总线、供电是否还在、线是否松动；不要用力顶机械限位。

| 实际动作 | 预期 ID | 需要记录 |
|---|---:|---|
| 夹爪开合 | 6 | COM3/4；真实左/右臂 |
| 肩部水平转 | 1 | COM3/4；真实左/右臂 |
| 肩部上下抬 | 2 | 方向是否与软件符号一致 |
| 肘部弯曲 | 3 | 活动范围是否顺畅 |
| 腕部俯仰 | 4 | 方向是否与软件符号一致 |
| 夹爪整体绕小臂旋转 | 5 | 是否被袖套或线缆阻碍 |
| 头部水平/俯仰 | 7、8 | 哪个轴对应哪个 ID |
| 左侧驱动轮前后转 | 9 | 确认“左边”定义与安装方向一致 |
| 右侧驱动轮前后转 | 10 | 确认“右边”定义与安装方向一致 |

当前预期布局来自源码，不能代替实物确认：

| 候选总线 | 预期内容 | 记录实际对应 |
|---|---|---|
| COM3 | 左臂 1–6 + 头部 7、8 | ________________ |
| COM4 | 右臂 1–6 + 左右轮 9、10 | ________________ |

如果移动一根轮子时两只 ID 同时变化、某一端机械动作对应另一根轮子，或者一个关节触发多个 ID，先停止动作并核对舵机串接线与支架安装方向。

完成标准：每个 ID 只对应一个明确的机械部件，左右和方向已经写在纸面/标签上；全程扭矩保持 OFF。

## 第二项：固定三路相机身份

1. 在实时调试页同时看见 CAM01、CAM02、CAM03 三幅画面。
2. 用纸片遮住第一个相机镜头，确认哪一个画面变黑；在相机外壳贴该页面编号。三台逐一完成。
3. 根据安装位置再写一行：CAM 编号 → 左腕/右腕/头部。当前页面标题只是候选，不能当作已确认。
4. 保持三台相机接在固定 USB 端口，插拔前先从页面/代码中释放相机。给线贴同样标签。
5. 在调试页与其他电脑上分别复核一次；相机编号可能在换机器或换插入顺序后变化。

记录表：

| 页面通道 | 设备实例或 USB 口 | 安装位置 | 遮挡验证 |
|---|---|---|---|
| CAM01 | ________________ | 左腕/右腕/头部 | 通过/未通过 |
| CAM02 | ________________ | 左腕/右腕/头部 | 通过/未通过 |
| CAM03 | ________________ | 左腕/右腕/头部 | 通过/未通过 |

完成标准：遮住任意一台，只有对应画面变黑；拔插并重连后，按固定端口恢复时身份一致。

## 第三项：手柄分阶段接管

### 当前状态

- Xbox Elite 2 已被 Windows 和调试页识别，但 Web 手柄区仅 DRY RUN。
- 官方现有 `5_xlerobot_teleop_xbox.py` 面向旧的三全向轮 `XLerobot`，不能直接控制 0.4 双轮 `XLerobot2Wheels`。
- 当前 Windows 插件入口是普通文本文件，不是有效链接；必须先修复插件/依赖，才能可靠安装和调用当前双轮机器人。

### 控制前必须完成

1. 完成上面两项实物映射。
2. 使用官方 SO101 流程，在托住机械臂且扭矩关闭时核对零位和各关节范围；保留已匹配实物和 ID 的校准文件。
3. 停止只读调试台，让出 COM3/COM4：运行 `fabrication/assembly/debug_console/stop.ps1`。
4. 机器人放在不会倾倒的位置，车轮离地或底盘可靠支撑，墙插线保持松弛。
5. 先测试单臂 1°–2° 的小步动作，再测试头部，然后单轮短时、低速，最后双轮。
6. 每一阶段都检查：松键停止、LB 松开停止、程序退出停止、USB/控制连接断开后 0.5 秒内停止。

### 目标按键设计

| 输入 | 动作 | 保护 |
|---|---|---|
| 按住 LB + 左摇杆 | 左臂 XY | 松开 LB 立即停止 |
| 按住 LB + 右摇杆 | 右臂 XY | 超时/断连立即停止 |
| LB + LT / RT | 左/右夹爪 | 夹爪速度限制 |
| LB + 十字键 | 前后、转向 | 首次离地、低速 |
| A/B/X/Y | 头部或模式切换 | 页面显示当前模式 |

首版不把“按一下就开始持续移动”做成默认行为。手柄失焦、窗口切走、USB 掉线或程序异常都必须结束动作。

### 代码落点

- 机器人类：`software/src/robots/xlerobot_2wheels/xlerobot_2wheels.py`。
- 当前配置：`software/src/robots/xlerobot_2wheels/config_xlerobot_2wheels.py`。
- 参考旧 Xbox 映射：`software/examples/5_xlerobot_teleop_xbox.py`。
- 不能把旧示例中的 `XLerobot`、端口或底盘方法直接复制；要实例化 `XLerobot2Wheels`，使用左右轮 9/10，并接入 watchdog、步长限制和停止命令。

完成标准：车轮离地时所有输入可控，任何松键、退出、断连、失去窗口或异常都能停止；之后才进行低速落地测试。

## 现在先做什么

先完成第一项和第二项。建议顺序：夹爪 ID6 → 肩水平 ID1 → 肩抬 ID2 → 肘 ID3 → 腕 ID4 → 腕转 ID5 → 头部 ID7/8 → 轮 ID9/10；然后逐台遮镜头。把每行实际 COM/ID 和左右/方向填写好，再进入校准与手柄控制。
