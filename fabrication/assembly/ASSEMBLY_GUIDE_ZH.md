# 本次到货的拼装与调试指南

日期：2026-10-23。对象：用户照片所示的 XLeRobot 双轮舵机套件。

依据：四张到货照片、本地官方双轮装配文档、推车手册和双轮软件源码。照片只能证明可见外观，不能证明整套齐全、型号正确或功能正常。本指南未经过本套硬件实测；每完成一步再记录结果，遇到问题在该步解决。

## 先花几分钟查关键件

不用逐袋数螺丝，先找以下几类：

- **电机控制板两块**：可能已装在两条机械臂底座附近，找有 USB 数据口、直流供电口、三针舵机接口的小板。图二底座附近疑似可见板件，但数量和型号不能确认。没有两块会影响双臂整机控制，仍可先组装推车。
- **电源两个**：图四已见两个适配器。读铭牌 OUTPUT；预期是套餐所述 DC 12V/8A，但照片没有拍到标签，不能当作已确认。同时确认舵机铭牌为 12V 版、插头尺寸和中心极性与板卡匹配。若标签不同，先停在无电机械安装阶段。
- **两根可传数据的 USB 线**：一块控制板一根，接头以板卡实物为准；不必强求三米长。照片中有多根长线，但不能判断都是相机线还是另含控制板线。
- **底盘/头部舵机**：图四有两个轮组和疑似头部云台；图二泡棉内有四只 Feetech 盒子。打开看看是舵机、配件还是空盒，检查轮架里面是否已经装了电机。不要只凭四个盒子认定有四只底盘舵机。
- **图二上方黑色长线的末端**：照片疑似露出彩色芯线。单独找出来检查：是断头、插头脱落，还是完整的小接头；有裸露导体就先隔离，不插设备、不通电。若它属于相机线，先跳过该相机，不影响其他部分安装。

可延后：头部第三路相机、USB Hub、车载迷你主机、充电宝转换线、备用螺丝、装饰袖套、VR、深度相机、自定义低位架。两只疑似腕部相机在图二可见；头部相机是否已装入图四组件无法确认。相机可在机械臂通电验证后逐个测。

工具先准备内六角和十字螺丝刀；小扳手/钳子用于推车轮子和螺母。万用表用于电源输出、极性及疑似坏线检查，不能靠试插验证未知供电。

## 1. 无电组装推车

1. 把白色推车零件与机器人黑色零件分开。按 [本地宜家原装手册](../../others/Manuals_raskog_utility_cart.pdf) 安装；款式不符时以箱内对应手册为准。
2. 先组装原推车，螺丝先带上几扣，等各层定位并放平后再逐步紧固，避免框架扭斜。四只原装脚轮均在照片中可见，先按推车手册安装；后续双轮改装是否拆换/保留其中部分，以本套轮架的官方装配视频为准。
3. 托盘数量被叠放遮挡，取出时确认，暂不需要逐件数小螺丝。
4. 本轮建议先按原套件安装高度验证功能。此前两层方案仍不能保证捡地面物体，低位前伸架还未完成实物验证。先验证原件再改高度，避免把装配问题与改造问题混在一起。

通过标准：空车不明显晃动，各层水平，脚轮能转动；不安装机械臂时也不扭斜。

## 2. 安装双轮底盘

使用 [官方双轮 B 站装配视频](https://www.bilibili.com/video/BV1JpiqBfEuf/)，对照 [双轮官方说明](https://xlerobot.readthedocs.io/en/latest/hardware/getting_started/assemble_2wheel.html)。该说明仍在建设中，三全向轮主教程不能作为本套底盘的安装图。

1. 趁上方未安装机械臂，把空推车侧放/倒放在软垫上，按视频识别两只轮架及固定件的方向。
2. 检查每个轮架是否已有舵机、轮毂紧固件和所需轴承。官方双轮文档提到 30×37×4 mm 轴承；可能已装在组件里，不要先拆开或重复购买。
3. 左右驱动轮按视频装到对应位置，确保轮面平行、轮胎不磨支架、线缆远离轮胎。螺丝长度以本套孔位和视频为准，不能把长螺丝硬拧进舵机壳体。
4. 放正检查驱动轮实际接地，车架无扭斜。脚轮与驱动轮的接地关系按官方装配，不凭猜测剪短立柱或强压支架。
5. 电机轴有减速阻力，不能以“断电时轮子不空转”判断卡死，也不要强扭。

通过标准：轮架不松动、不裂，轮胎无干涉，电机线不落地。首次电动测试必须可靠支撑车体，使两只驱动轮离地。

## 3. 安装上部底座、双臂与头部

1. 图四的大黑色板件按视频核对正反、上下及夹紧关系，先空装到托盘确认孔位，不把外形相近的板件默认当作左右同件。
2. 两条手臂已经大体装好，先不拆关节、舵盘和袖套。只将底座接口固定到双臂安装座；操作时托住手臂，不能悬着让一颗螺丝承重。
3. 两臂的左右按机器人面向前方时的左右标记。夹爪朝前，关节周围留出活动空间；先支撑手臂，避免断电垂落。
4. 安装头部云台和相机支架；缺头部相机时空着即可。线缆预留转动余量，不绕轴缠死。
5. 初次只收拢线缆，不把扎带锁死；确认全行程后再收紧。优先利用原有开口走线，当前不需要照旧三轮教程剪托盘网格。

通过标准：底座夹紧，无明显摇晃；结构件没有强行掰装的裂纹；手臂和头部线缆不夹在安装面之间。

## 4. 单板连接、先读后写

这一步开始才需要外置电脑。电脑可以放在桌上，通过 USB 调试，不是车载设备。手机作为后续终端，不替代这一步的板卡诊断。

1. 所有适配器先断开；核对两块板和舵机的供电规格、插头极性。给板贴 L/R，给 USB 线贴同样标签。
2. 先只连接一块控制板的 USB 到电脑，确认串口。Windows 可用设备管理器，或只读命令：

   ```powershell
   Get-CimInstance Win32_SerialPort | Select-Object DeviceID,Name
   ```

   插拔对比确认哪一个 COM 对应哪块板；没有输出不等于板坏，继续查驱动和 USB 数据线。
3. 舵机总线的线序必须按板上标识确认，不能只看红白黑颜色。现有机械臂内部串接先保留；从未接过的轮组、头部先单独确认。
4. 接线完成、机械臂已被支撑后，最后接对应的直流电源。先用随套墙插电源；暂不接 Anker 充电宝或未经验证的 PD 触发线。
5. 官方推荐 [Bambot Feetech 页面](https://bambot.org/feetech.js)。用支持 Web Serial 的桌面 Chrome/Edge，连接对应 COM，先只扫描/读取 ID、位置、模式；工具若提示默认动作或使能扭矩，不要直接执行。记录当前配置，不先点位置滑块、设置 ID 或恢复出厂。
6. 每换接舵机线都先断直流电源，必要时同时拔 USB 防止板卡反向供电；插接完再供电。不得把两块独立供电板的电源输出互相并接，手臂/头部/底盘也不要误串成两板同一总线。

### 必须先解决的版本差异

- 本地源码 `software/src/robots/xlerobot_2wheels/xlerobot_2wheels.py` 当前定义：L 总线手臂 ID 1–6、头部 7/8；R 总线手臂 1–6、左右轮 9/10。
- 旧三轮装配文档写底盘 7/8/9；此前卖家套餐描述又写四只底盘舵机。三者不能直接混用。
- 四只盒子也可能含头部电机或备件。先记录每只实物的位置、型号和原 ID；如确实每个驱动轮有两只主动舵机，当前“两只轮电机”的源码不能直接控制，必须先厘清联动方式并适配。
- 二手手臂可能已编号，不重跑 `setup_motors`。确有重复 ID 时，断电后一次只接一只需修改的电机，再编号；同一总线不能留重复 ID。
- 本指南仅列出源码默认 ID，不代表要求用户现在改成这些数字。

通过标准：两块板分别识别，按物理组件记下全部实际舵机；无异常发热、焦味、持续大电流。若有异常立即断对应直流电源并检查，不靠重试动作排障。

## 5. 按顺序做小动作调试

整机程序会配置电机模式、增益并使能扭矩，因此“启动整机”本身不是只读测试。完成上一步映射和供电核对后，才准备匹配的软件环境与单关节测试。

1. **单臂**：先让另一臂、头部和轮组不参与，支撑待测臂，以当前位置为起点测试单关节很小的位移。逐个确认肩转、肩抬、肘、腕、夹爪的方向及机械限位，不从“归零”或大幅动作开始。
2. **另一臂**：同样方法。无异常再做校准；校准时软件会关闭扭矩，先托住手臂。按提示慢慢移动各关节到实际可达范围，不顶住托盘、夹断线缆或硬压止挡。保存本机校准文件，卖家的文件需匹配实物与 ID 才可复用。
3. **头部**：单独小幅测试两个轴，先确认零位和线缆余量，不做整圈旋转。
4. **轮组**：驱动轮离地，小速度短时测试单侧，再双侧；确认左右、正反和停止命令。不让处于位置模式的轮电机强行做连续转动。
5. **停车验证**：测试停止指令、程序退出、控制连接中断时是否停止；软停止失败时断电，之后修复再落地。断电可能使手臂下落，应事先支撑和留出空间。
6. **相机**：每次只插一台，用 Windows 相机应用或 UVC 测试程序确认出图，遮住镜头验证实际位置，再标记左腕/右腕/头部；USB 插入顺序不能当作永久相机编号。最后才三路同时测试掉帧/断连。
7. **地面**：收拢双臂，空载，低速前后短距离及转向；拖着墙插线时只做线长范围内的小移动，禁止原地多圈绕线。

## 6. 软件现状与后续接入

- 官方安装入口：[install](https://xlerobot.readthedocs.io/en/latest/software/getting_started/install.html)。本机调试应建单独的硬件虚拟环境，不复用或改坏现有仿真/CAD 环境。
- 本次只检查源码，尚未安装硬件环境或连接实物。Windows 当前克隆把两个插件符号链接检出成了保存相对路径的普通文件：`software/plugins/xlerobot_model/xlerobot_model` 和 `software/plugins/lerobot_robot_xlerobot_2wheels/lerobot_robot_xlerobot_2wheels`。安装插件前需处理 Windows 链接/打包问题，并确认 LeRobot 依赖版本；不直接照抄 pip 命令宣称可用。
- 当前默认相机配置为空，轮半径默认 0.05 m；实际轮径若为 127 mm 应测量后填写，不能直接当默认 100 mm 轮使用。
- 单关节、校准、轮组、停车和三相机通过后，再接手机网页控制；需要独立供电 Hub/迷你主机时再补件。
- 手机、家中台式机与车载网关的规划见 `PROJECT_ARCHITECTURE.md`。PICO、VLA、地面抓取改造均在基本控制通过后推进。

## 遇到问题停在哪一步

- 推车孔对不上：先核对杆件、夹片方向和手册型号，不钻孔硬改。
- 轮胎磨壳/轴不对中：检查支架方向、轴承和垫片，不用加大扭矩补偿。
- 板不出现 COM：换确认可传数据的 USB 线、直连电脑、查 USB 芯片驱动。
- 有 COM 但读不到舵机：查直流供电、TTL 接口、线序、波特率；断电后分段接入，先读一只。
- 只读到一部分：检查串接链路、延长线和重复 ID；不能立即认定缺电机或坏电机。
- 一动就断连/重启：先查电源输出、压降、接头及 USB 供电，减到单组件，不先改 PID。
- 持续嗡鸣/发热/位置不动：停动作并断电，查卡住、限位、装配及校准，避免持续堵转。
- 轮子不停：先断对应直流供电，车轮仍保持离地，核对模式和停车逻辑。
