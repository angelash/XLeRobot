# XLeRobot 地面拾取方案仿真结论

本实验比较如何从地面捡起垃圾或玩具，同时评估能否保留桌面操作能力。

## 对比方案

1. **A 原厂三层高位**：双臂在最上层，原安装姿态。
2. **B 纯两层**：去掉顶层托盘，双臂降至中层，高度约降低 0.28 m。
3. **C 两层 + 向下 90°安装**：不改变高度，但翻转机械臂基座。
4. **D 两层 + 前伸 0.10 m + 向下 90°**：把工作区移出托盘前沿。
5. **E 低位前伸架**：臂根高约 0.30 m，向前 0.12 m，并向下 90°。
6. **F 长工具**：中层下翻后增加 5/10/15 cm 的刚性向下延伸。这是概念附加件，没有完整工具碰撞网格。
7. **G 升降底盘**：地面任务降至约 0.30 m，桌面任务升回约 0.7865 m。

## 测试方法

- 使用仓库中的 XLeRobot MuJoCo 机械臂与真实夹爪网格。
- 用夹爪网格离玩具的最近距离衡量可触达性。
- 用简化拉斯克托盘、桌板和立柱做碰撞筛选。
- 地面玩具中心为 (0, 0.40, 0.045) m。
- 桌面玩具中心为 (0, 0.40, 0.72) m。
- 成功阈值：最近点距离不超过 0.06 m，且碰撞穿透小于 3 mm。

该结果用于排除明显不可行方案，不代表已经完成真实抓取、夹持稳定性、重心、轮胎打滑、线缆干涉或相机可视性验证。

|---|---:|---:|---:|---:|---|
| A 原厂高位 | 0.552 m | 0 | 接近 0 | 0 | 桌面可用，地面不可用 |
| B 纯两层 | 0.280 m | 0 | 接近 0 | 0 | 地面仍不可用 |
| C 中层下翻 | 0.096 m | 28.4 mm | 0.077 m | 27.5 mm | 改善明显，但撞托盘/桌板 |

## 推荐

### 当前目标：捡地面垃圾和玩具

首选 **E 低位前伸架**。它在地面测试中达到目标且没有简化托盘碰撞，改动量也明显小于升降机构。

建议做成可拆的低位前侧支架，保留原中层安装板。需要桌边操作时换回高位配置。

设计要点：

- 前伸支架使用金属加强件或高填充/高刚度打印件。
- 增加底部碰撞保险、限速和急停。
- 重新标定双臂零位、相机外参和夹爪工作空间。
- 把线缆固定到支架背面，避免轮组和机械臂缠绕。

### 需要不换装地兼顾地面和桌面

选择 **G 升降底盘**。它在两种高度均通过当前简化测试，但机构、锁止、重心、线缆和成本都更复杂。

### 不建议直接采用

- **B 纯两层**：夹爪仍离地约 0.28 m。
- **C 仅下翻**：会撞托盘和桌板。
- **D 中层前伸下翻**：接近地面但尚未达到阈值，桌面也撞板。
- **F 长工具**：需要真实工具碰撞和力矩验证，当前只能当作概念筛选。
