## 资料怎么用

先读某天摘要和结果，再看问题、后续与经验。需要核对时使用来源编号回到对应会话；原始 JSONL、工具记录和照片保存在私人快照，整理稿不代替原文。

`index.html` 是自带全部整理数据的单文件，可直接离线打开、搜索、切换日期和打印；分享这个文件即可阅读全部日报与经验。Markdown 和 data.json 便于继续修订。
