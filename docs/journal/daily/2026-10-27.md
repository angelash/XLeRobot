# 2026-10-27 · 双板从单侧异常恢复，搭起只读调试台

阶段：接线与只读检测。时间口径：北京时间；本批对话截止 2026-11-03 14:46。

先定位 USB、供电和串口占用问题，随后读到两块板共 16 个电机，开始把设备状态和动作许可做成可视面板。

## 当天推进

- 早期 COM3 可读、COM4 打不开；COM3 反馈电压从约 5V 变为正常 12V，表明动力供电与 USB 枚举需要分开检查。
- 识别另一程序占用串口的情况，保持已有程序与现场状态，避免同时争抢总线。
- 双板恢复后，COM3 的 ID 1–8、COM4 的 ID 1–6/9/10 均有应答，共 16 个电机。
- 创建本地只读调试台，展示舵机遥测、相机、手柄输入，以及观测/校准/受限控制许可。
- 用户断开设备后准备受限控制软件：当前位置保持、按键单步、停止和断连处理，并补齐实时状态反馈。

## 问题与失败

- 串口存在不等于能打开，USB 供电存在不等于舵机动力供电正常。
- 网页能看到手柄输入，仍不能证明电机已收到可执行命令。

## 当日结果与边界

两板与电机拓扑已得到只读确认，受限控制软件就绪；没有据此认定完整手柄实机控制已通过。

## 后续事项

- 确认物理左右臂、关节与编号对应。
- 保持单一串口所有者，先做当前位置保持和小步验证。

## 可复用经验

- 把设备在线、动作许可、输入、下发与实际反馈分开显示。
- 逐层排查 USB、动力供电、串口占用和总线应答。
