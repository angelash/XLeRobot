# 2026-11-02 · 自主观察、MOSS、整机参考与有限移动并行推进

阶段：多模块实测与交付。时间口径：北京时间；本日整理依据截止 2026-11-03 14:46。

第一轮自主观察完成，交叉视角与待审经验制度建立。Studio 增加空间观察、机器人展示、语音和自主学习；短移与建图保留明显限制。

## 当天推进

- 第一轮自主运行确认头部/左右腕相机对应，补测行程，修正退离与受阻判据。用另一条收起手臂的腕相机从侧面观察前伸手臂，补足笔记本视角。
- 建立已审核规范、观察手册、待审核经验三层资料；待审核经验默认参与判断，但不能放宽硬性边界。观察手内转造成碰撞的失败也归档。
- 车载小九桥接、持久会话、去重和超时/取消/崩溃处理落地；完整源码同步与运行发布分开核对。
- 空间观察从 31 张图/17 项标记发展到 68 张/23 项，最终为 101 张/26 项。先前独立观察服务退役，能力并入 8770。
- MOSS 展示接入署名模型、固定吊顶与独立关节，修复局域网消息发送，加入人设、MiniMax 语音和十套待机动作。早期浏览器失败与后续实际页面复验均保留。
- 语音输入默认关闭，名字唤醒、持久对话和静默交付完成；真实麦克风与有声效果按用户要求留待现场测试。
- 通过受限自检补齐双臂运动学参考和夹爪端点，验证可启动待机姿态与低速联动；精确定位仍未完成测量标定。
- 朝过道完成 5 次低速短移，因人和椅子停止，未到开阔过道。后续两次以 5cm 为目标的尝试提前保护停车，编码器估算累计约 3.1cm，未到红线。
- 增加自主学习、双目标定工具与算力路由；远端只提供加速建议，本地控制器保留最终动作与停车权。

## 问题与失败

- 轮 10 动作中曾报告 57°C、停车后 35°C，原因没有查清，自主移动暂停。
- 手柄操作和轮位变化后地图定位失效；照片方位图、红线和编码器估算都不足以构成可靠地面围栏。
- 首次展示与关节测试存在失败；不能引用早期未通过的阶段，也不能用后续修复抹去当时失败。
- 语音链路有 CLI 收尾延迟；静默逻辑通过不代表实际语音体验已验收。

## 当日结果与边界

自主观察、多个 Studio 模块与整机初始化有实测交付；自主导航、可靠围栏、精确定位、通用双目抓取仍未完成。实时避障的部署结果跨到次日记录。
