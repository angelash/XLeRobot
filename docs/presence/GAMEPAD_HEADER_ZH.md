# 展示顶部手柄状态与菜单键接管

日期：2026-11-02。需求：声线试听移入设置；展示顶部实时显示车载手柄连接、接管状态、实际模式与回退原因；默认未接管，Menu开始/取消，整机联动优先，必要时回退预设直控。

## 交互与控制边界

- 顶部保留简洁的连接、接管和模式摘要。首次连接和网页打开均不开始控制，展示页不使用浏览器Gamepad API读取工作端手柄，也不发送启动/驱动命令。
- 唯一8765串口所有者持续读取笔记本原生XInput。确认连接后先见到松开的Menu，再接受新按下；按下时其余输入需回中，松开Menu后才准备控制。长按、重连时已按住的Menu不重复触发。
- 已接管时再次按Menu结束接管并保持当前位置；准备中再次按Menu、View、断开或偏离回中会取消。原生接管掉线后不自动恢复控制，重新连接后需重新按Menu。网页关闭不改变车载手柄会话。
- 启动复用整机联动的标定/姿态、供电、温度、串口、采集/自检互斥和保持当前位置逻辑。只有明确的联动配置/IK分支不可用才尝试预设直控；通信/供电等通用错误不以回退绕过，启动失败显示原因。
- 串口准备在独立工作线程完成，XInput采样继续更新；准备期间不会执行摇杆输入，结束前再次确认输入回中、请求未取消，禁止旧输入重放。测试只在假总线/假手柄执行启停，不代替用户在实体手柄上开启控制。

## 实时状态

- 8765维护只包含操作摘要的事件快照，连接、启停、暂停、模式、回退和故障改变时发布；SSE提供初始快照、变更和心跳。
- 8770的展示模块只读转发这一路SSE，页面通过EventSource订阅。无前端状态轮询；流中断显示“状态未知”，不把网页断连误写成实机已停止。
- 顶部显示“手柄未连接/已连接”“未接管/等待松开/准备中/控制中/已暂停/启动受阻”和“整机联动优先/整机联动/预设直控”。回退原因在摘要和悬停说明中可见。
- 声线试听入口放入设置的语音区域，保留全部声线、试听与选择；返回设置不丢失未保存的角色表单。
