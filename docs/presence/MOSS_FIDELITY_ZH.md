## 从观察到实现

`presentation/static/moss-detailed.js` 生成几何、材质与标签；没有对参考照片自动拟合网格。比例根据多视角视觉关系手工设定，没有工程尺寸和相机标定，不宣称毫米级精度或相似度百分比。

- **整体轮廓**：将首版近似对称的摄像头盒子改为左上切角、右侧阶梯凹口、底部设备桥的不对称机体；同时建立有厚度的侧壳与后维护门。
- **光学系统**：增加斜向光学底板、多层镜筒、金属内圈、周向细节、前缘卡扣、玻璃反光、小副镜头和右上圆形栅格。核心采用红色发光环与暗色孔径，避免只剩一个白色亮点。
- **前面板**：增加左突起扬声器、纵向通风区和斜撑、小型诊断屏、接口与紧固件。屏幕和标签是静态原创图案，不冒充真实设备读数。
- **悬挂结构**：增加右侧俯仰轴、下肘壳、纵向圆柱、散热/伸缩环、顶部双枢轴与悬挂导轨。镜头机身围绕右侧关节做小幅展示微动，挂架保持连接。
- **底部与背部**：增加设备插槽、折角附件、后维护板、散热孔与固定条。反面仍是视觉近似，内部结构、布线、机械装配与真实关节行程没有重建。
- **材质与呈现**：使用灰白壳体、深灰金属、橡胶、金属扣件、光学玻璃和红色发光材质；当前没有电影级磨损贴图或扫描纹理。按材质合并网格，保持本地依赖和按需重绘。

人工检查正面、前侧、侧面和背面截图后，修正过脱离斜切边缘的紧固件、被外框遮住的诊断屏/铭牌，以及悬挂轴的可见断缝。该检查确认轮廓与连接的可读性，不等于与原始 924464 网格逐顶点比对。

## 配置与交付方式

- 默认 `avatar.kind=procedural-moss`、`avatar.detail=detailed`；设置可选 `simple` 保留首版。旧配置缺少 `detail` 时读取为详细版，读取不覆写原配置文件；用户保存后才持久化新字段。
- 自定义图片/GLB、名称、人设、署名、过程收起居中与视觉区沿用原框架。`detail` 仅选择内置版本。
- 展示入口：`http://127.0.0.1:8780/presence/`。
- 检视入口：`http://127.0.0.1:8780/presence/assets/model-inspector.html`，可选正面/前侧/侧面/背面、拖动、缩放、角度滑杆以及详细/简版对照。
- 检视页可导出自包含 `moss-550w-detailed-v2.glb`，几何与 Canvas 生成纹理一并打包；导出清除运行时对象引用，并写入可序列化来源说明。导出是静态形象，不含前端微动代码、实体控制或骨骼动画。
- GLB 可重新导入现有展示页；保留 20MiB 上限、外部 URI 和必需解码扩展拒绝规则。可选标准材质扩展由本地 Three.js 提供，不增加联网解码器。

## 实测与证据

工作端最终模型 **67,538 三角面、24 个渲染网格**。该数值是网格统计，不是计入阴影等额外遍历的 GPU draw call 实测。实际导出的 GLB 为 **6,551,180 字节，约 6.25MiB**，SHA-256：

```text
dcbcc41d23a4889c38ad255aaa9c583b76c677848ff78d16a1b5bd4c7db836e9
```

验证结果：

- 展示后端、车载消息桥与 Studio 聚焦回归：**53 passed**，包括旧配置默认值、磁盘原文件保留、简版保存及非法版本拒绝。
- 前端事件状态测试：**3 passed**。
- 本地 Chromium：实际 WebGL 渲染、详细版四方向、角度键盘输入、GLB 下载、后端校验和重新导入显示、简版切换均通过；原有收起居中、图片分析、配置持久化、SSE 重连和减少动态效果回归通过。
- 页面尺寸：1366×768、1920×1080、2560×1600、390×844；浏览器验证期间页面错误 **0**、外部 HTTP 请求 **0**。
- Three.js 固定版本仍为 0.180.0，本轮增加 MIT 的 GLTFExporter；现有五个文件字节未改，六文件 SHA-256 按清单核对。

本地证据目录为 `.local-deploy/presence-qa-v2/`：`verification.json`、四方向截图、检视整页截图、详细 GLB、主界面与窄屏截图。`.local-deploy/moss-924464/` 保存视觉参考、来源清单和首版截图；生成的新旧模型对比图为 `.local-deploy/presence-qa-v2/moss-comparison.jpg`。这些文件留在本地，不进入公开 Git。

使用的软件渲染检查不证明车载 MX250 的真实帧率或温升；本轮只更新工作端独立展示预览，未重启车载控制/智能服务，也未操作实体机器人。首版其他接入边界继续以 [验收记录](ACCEPTANCE_ZH.md) 为准。
