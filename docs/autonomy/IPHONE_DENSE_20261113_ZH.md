# iPhone 固定视野稠密重建 · 2026-11-13

本次将普通 iPhone 12 的 Record3D Wi-Fi RGB-D 接入既有 Studio 空间观察页，并实际生成局部彩色三角表面。它改善当前可见区域的几何展示；尚未完成整屋、多机位连续重建、回环、机器人坐标配准或导航验收。

## 来源与当前边界

- **用户陈述**：iPhone 固定在车上，已选前置 TrueDepth。设备并非新购；接口没有返回镜头类型，不能把该选择写为程序独立识别。
- **系统核验**：Record3D 原始尺寸480×640、焦距约435.264像素；流会调整到180×240，接收端按每帧尺寸缩放内参。不同分辨率不合并。
- **数据语义**：当前 Wi-Fi 深度由色相视频还原，`record3d_hue_video / sensor_raw_depth=false`。没有原始传感器浮点深度、逐像素置信度或相机Pose；有损传输和已知距离标定的缺口保留。
- **物理状态**：本次没有底盘、手臂或头部动作。此前回正18双轮−87／−58及卸力后回退的异常未解除；右肩 COM3:2 物理hold保留。保持原保护停车，不以换相机代替轮组检查。

## 已生成的真实局部表面

1. 会话 `e4d8faa2c6804ddda948a06cc2362d1f`：45组不同RGB-D，180×240，采集无取图错误。0.2—2.5米有效像素中位58.10%，范围内深度中位约1.36米。与前轮安卓约1.6—1.9%的记录相比，本次数据可用性明显改善；设备、时间、视角和统计窗口不同，不作为受控精度对照。
2. 初始逐帧RGB-D＋ICP估计在静止机位产生约4.3厘米累计位移。按用户确认的固定条件，改为零位姿融合，保留配准检查作为拒绝门；不把这段估计漂移写为车身移动。
3. 固定视野时间中位滤波要求至少60%帧有实测、像素中位偏差不超过4厘米；再做8毫米TSDF融合。8毫米是网格参数，不是测距误差。结果 `9c0b2501b4a34f88bb466534b85cb8e4`：45/45帧、85,392顶点、145,012三角面；稳定像素55.13%，最大连通分量占三角面73.73%。未见像素不补洞。
4. 网页首轮高分辨率采集在第23组写清单时遭遇Windows临时文件替换拒绝，原任务 `f6da87f9c37d483cb35131cb85d415c9` 及已落盘22组480×640数据保留。另建来源关联的副本，在车载独立环境实际融合22/22帧，结果 `ee37f20276e34fc3a0f63a0b079a8885`：86,546顶点、146,935三角面，范围内像素中位54.38%，稳定像素53.3%，最大连通分量84.12%。原失败任务不改成成功。

连通分量比例只说明当前局部模型的拓扑连通性，不是房间覆盖率。照片里可见的桌椅、地面已有彩色表面，边界、遮挡、噪声和远处仍有空洞；固定机位不会增加背面信息。

## Studio 使用

- 入口仍是 `http://192.168.137.150:8770/#fieldmap`，空间页内选择“彩色表面 · iPhone”。支持表面／点阵切换、原拍摄视角、旋转平移缩放、来源照片、深度支持度、PLY和融合报告。
- “最近收到的手机画面”支持自动、iPhone、安卓选择。并行读取同帧RGB、深度及覆盖统计；完整解码后才替换显示。失败保留上一张完整图并标过期，不延长原1秒控制源龄。
- 手机和车身静止、Record3D前台实际采集时，点击“采集固定视野 · iPhone”，有界采集30个不同的新鲜帧，再由车载CPU融合；最多20秒采集、150秒融合。同一时间一个任务。该按钮不移动机器人。
- 帧数、拒绝、原始RGB-D、融合结果分别留档。分辨率、内参、深度来源、会话或时间连续性变化时结束本段；旧AR分卷与地图独立保存。
- 本次可用的是固定视野工作流。CLI的短程RGB-D里程计入口仍属实验能力，不等于全屋SLAM；禁止用局部模型直接放行底盘。

## 实现、安装与验证

Studio本身不导入Open3D；车载独立 `.venv-dense` 安装 `deployment/phone_vision/requirements-dense.txt`，实测Open3D0.19.0、OpenCV4.10.0、NumPy1.26.4。串口控制环境不安装这些包，也不增加端口或开机服务。

`deployment.phone_vision.dense` 可从不可变 `frames.json` 和对应源文件重建；输入保存会话、序号、内参、RGB／深度SHA。结果清单保存每个公开产物的大小与SHA，读取时核验。展示PLY／JSON采用相机OpenGL坐标，完整原网格PLY采用OpenCV坐标，报告分别说明。无回环、无全局尺度认证、无地图配准。

新增 `/api/platform/phone-vision/dense*` 路由位于原8770应用；同源写入、严格固定请求字段、精确ID和媒体白名单、文件大小与哈希检查保留。Windows原子替换使用唯一临时文件及有限重试；失败详情保留本地，不将内部路径放进产品提示。Studio退出会终止本次可选融合工作。
