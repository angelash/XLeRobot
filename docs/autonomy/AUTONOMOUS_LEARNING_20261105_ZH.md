## 下一轮学习方法

1. 固定硬件与场景范围：全臂姿态、夹爪衬垫、物体朝向、速度、扭矩与相机位姿。条件改变另开组，不把成功拼到新组。
2. 每个能力保留训练、整次物理尝试留出、失败及未知；先本地旁路预测，再做有界受监督执行，成功才考虑扩展范围。不能把模型自己的预测当新真值反复训练。
3. 轮速先按100/120/160/200各采≥3次，对比运行点查表/分段模型与直线模型；当前100/120平台现象未解释前不外推死区。停车仍依编码器与时限，模型只帮选小段参数。外部距离、转角等有尺量/标记物后再完成原W2/W3，不重复已有方案。
4. 抓取下一步优先稳定对向包覆和视觉试提复核，继续保留材质/估计重量档案及原压力门。加入试提后的压力保留和独立视觉标签，再做新物体留出；单凭闭合四维特征已暴露漏判，不能直接取代抓起/搬运/放下验证。
5. 视觉先把助手框选转成本地跟踪，丢失、遮挡或范围改变交回识别层；几何和接触不确定时停车观察。测距仍需原相机/手眼标定，不用高相关分填补深度缺口。
