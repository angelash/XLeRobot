## 当前证据与结论

**工程核验**：`deployment/fieldmap` 已有照片、环视、空间示意、轮估历史和人体/整车包络预览；`deployment/phone_vision` 已有手机RGB-D、AR点云与固定视角稠密表面。这些结果不等于连续米制SLAM。2026-11-13交接仍记录轮组动态异常、右肩物理hold、iPhone无线流恢复缺口；这轮研究与软件开发不恢复运动、不唤醒车载电脑。

**当地配置核验**：WSL的Home Assistant登记了追觅S10，内部型号`dreame.vacuum.r2228`，登记固件`4.3.9_3032`，Dreame集成`v2.0.0b25`。当前152个Dreame实体均为`unavailable`，两个地图相机的已有数据接口返回404。没有取得真实房屋栅格、房间坐标、轨迹或可配准模型。型号和固件来自登记，不是本轮与实体设备通信得到的读数。

**后续云端刷新核验**：用户要求更新新设备后，集成目录从42台同步到44台、原设备全保留。新增米家扫拖机器人6 Pro（`xiaomi.vacuum.pv21cn`，本轮云端固件`4.5.8_0758`、在线，HA停靠/电量100%），读到9个房间条目、2个地图记录与地图/轨迹对象引用；3D字段为空。此前结论仅覆盖旧HA实体，现由[刷新记录](XIAOMI_6PRO_REFRESH_ZH.md)补充。当前尚未下载、解码对象引用对应的实际栅格，不能把新设备元数据等同于导航地图已可用。

**文献与开源实现核验**：37项候选中34项成功取得；S01、S26、S30保留403/404等获取缺口，不作为已读正文论据。初始两个arXiv标识指向无关论文，已由题名核验排除并改用JOSS原文及RTAB-Map项目原始出版索引；账本保留失败尝试。ROS文档有HTTP200验证页面，未计作有效文档，改读官方消息源码。Nav2失效文档链接改读官方实现。S03为扫描PDF，直接查看第一页核对作者、摘要和frontier定义，未把空文本提取当作全文阅读。资料覆盖经典方法、维护中的实现和接入协议，不宣称穷尽全部论文、所有机型或闭源固件内部算法。

## 从资料到工程决策

1. Thrun《Robotic Mapping: A Survey》(2002, S02)：区分已知位姿建图与联合定位建图；用概率表示观测和定位误差，不能凭照片/稠密点数证明地图准确。
2. Yamauchi《A Frontier-Based Approach for Autonomous Exploration》(1997, S03)：frontier是已知自由与未知的边界。目标应在可达的已知自由区一侧，再以新观测拓展地图；不能直接向未知栅格发车。
3. Hess等《Real-Time Loop Closure in 2D LIDAR SLAM》(2016, S04)、SLAM Toolbox (2021, S05/S06)：激光扫描匹配、位姿图和闭环承担连续定位/漂移纠正；长期保存位姿图与原始扫描，闭环后重建栅格。第一阶段不自行重写一个未经验证的全功能SLAM。
4. REP-103/105与LaserScan (S07/S08/S29)：米、弧度、右手系、`map → odom → base_link → sensor`及时间戳是契约，手机AR与扫地机坐标不能直接拼接。
5. Nav2成本地图与碰撞监测实现 (S09–S13)：全局静态地图、近场动态障碍、膨胀及独立停车各司其职；2D雷达没有看见的桌沿、线缆、跌落边缘不能因此变自由。
6. RTAB-Map (S15/S16/S33)、ORB-SLAM3 (S17)：RGB-D/视觉惯导是可行的定位路线，但需要真实内参、尺度、同步、标定和失跟踪恢复。当前Record3D无线色相深度不能直接当作合格的导航RGB-D输入。
7. Choset/Pignon Boustrophedon (1997, S19)、Fields2Cover (S20)：全覆盖路径与发现未知区域是不同问题。先完成建图/定位，再按分区生成往返覆盖；Fields2Cover面向农业车辆，不能无调整照搬室内推车转弯。
8. Valetudo、Dreame与Xiaomi地图提取资料 (S21–S25)：可导出的通常是栅格/房间/轨迹/禁区等二维表示，不是保证存在的家庭3D模型或原始激光流。高矮、宽窄、坐标时期与地图时效必须独立处理。

## 技术选择与范围

- 推荐稳定路线：可验证的2D激光扫描 + 轮编码器里程计 + IMU，经SLAM Toolbox或等价成熟后端提供连续定位；RGB-D补充高度层与近场障碍。增加硬件仅为建议，当前未采购、未确认已有雷达/独立IMU。
- 现有设备路线：先严格验证手机RGB-D/AR与机器人安装外参；合格后试RTAB-Map。无法提供可靠尺度/位姿时保留观察层，不释放导航。
- 本轮已开发：无大模型依赖的测距/位姿输入契约、占据栅格、未知保护、保守膨胀、可达frontier、A*预览、持久回放/导出恢复、外部地图先验隔离及原Studio可检查入口。具体完成范围见[验证与交接](VALIDATION_ZH.md)。
- 下一阶段：真实数据只读回放、独立SLAM工作进程、时序/标定验收，最后才连接原8765受保护控制链。阶段一不冒称完成闭环SLAM、传感器验收或实机自主建图。
