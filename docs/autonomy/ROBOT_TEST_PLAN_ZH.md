# 明日机器人测试方案：标定、轮—地学习与双目抓取

日期：2026-11-02编制，供用户准备好后执行。实验定义见 [学习方案与规范](LEARNING_PROTOCOLS_ZH.md)。执行前助手照常读三份控制文档、核对设备身份与空闲状态；每段动作后停车核验并重拍；检测到手柄接管、通信或读数异常即停止并保留现场。

## 1 用户需要准备

| 物品 | 用途 | 说明 |
|---|---|---|
| 打印的棋盘格 | C1/C2/C3/C4 | `docs/autonomy/assets/checkerboard-9x6-25mm.pdf`，A4横向**100%实际大小**打印，不要“适合页面”；量一下10个方格应为250mm；贴在硬纸板或平板上保持平整 |
| 打印的AprilTag | W3、地面/墙面参照 | `docs/autonomy/assets/apriltag36h11-80mm.pdf`，同样100%打印，黑色方块边长应为80mm |
| 卷尺或钢尺 | 真值 | 量地面位移、物体距离 |
| 纸胶带 | 地面刻度 | 在机器人前方贴一条与车头平行的起始线 |
| 架空垫块（可选） | W1 | 让驱动轮离地空转；没有就跳过W1 |
| 2–3个小物体 | A4/G1/G3 | 不易碎、宽20–50mm、颜色与地面区别明显，如胶带卷、方盒、软球 |
| 清空的测试区 | 全部 | 人员不在手臂和车体运动范围内 |

## 2 建议顺序与时间

| 顺序 | 内容 | 动作范围 | 预计 |
|---|---|---|---|
| 0 | 预检：身份、16电机、电压温度、相机出帧；W0静止读数采样 | 不动 | 10分钟 |
| 1 | C1：三路机器人相机+笔记本相机内参（用户手持棋盘格变换位置，助手逐张检查） | 头部/手臂可调整视角 | 30分钟 |
| 2 | A2+C3：双臂观测姿态往返重复性与双目标定 | 手臂在已知范围内 | 30分钟 |
| 3 | G1：已知距离物体测距 | 不动或微调头部 | 20分钟 |
| 4 | C2：头部导航姿态的地面单应 | 头部 | 15分钟 |
| 5 | W1（可选架空）→W2→W3→W4 | 底盘按计数分段 | 40分钟 |
| 6 | A1/A4：关节阶跃与夹爪开口 | 单关节小步 | 30分钟 |
| 7 | G2→G3：预抓取与抓取尝试 | 单臂低扭矩 | 40分钟 |

顺序可按现场调整，但抓取（G2/G3）必须在C1、C3、G1达标之后。

## 3 每项的通过与停止

- **C1**：每相机≥15张有效图，重投影RMS≤0.8px；不达标补拍角度更斜、更靠边的图。
- **A2/C3**：观测姿态重复5次，标定板位姿离散≤2mm/0.3°；超出说明回程误差大，改为每次测距前现场重标。
- **G1**：0.25–0.6m内≥10个点，误差≤1cm；超出时先查C1/C3残差，不进入抓取。
- **C2**：至少3个验证点误差≤1cm；之后红线等地面边界改用厘米坐标表示。
- **W2/W3**：每档≥3次，残差达门槛后有效轮径/轮距标为候选模型；W0中出现的温度/读数跳变在W系列中复现时立即停，保留原始寄存器。
- **G3**：每次抓取前重新观测；夹爪全闭或负载未上升判为未夹住；任何意外接触按AGENT_CONTROL第10节先保持现场再观察。

通用停止：手柄接管或输入、画面中有人进入运动范围、温度≥55°C或异常跳变、电压连续低于10.5V、通信错误、编码器停车证据不全、观测超过60秒。

## 5 算力使用

- 标定板检测、单点三角测量、地面单应换算在笔记本完成。
- 批量标定求解、全分辨率视差、识别复核优先送工作端；工作端离线时笔记本执行（更慢但可用）。
- 目标识别、成败判断在L0阶段由大模型完成，并作为本地算法的标签来源。
