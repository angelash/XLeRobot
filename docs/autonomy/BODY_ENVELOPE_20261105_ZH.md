# 整车体积与转身扫掠：粗略模型及退离实测

2026-11-05用户确认转身时车体卡住，提供整车贴近桌边照片，要求建立粗略体态、移动时考虑自身体积，先向前让出转身空间再继续。这补充了上一轮L-094中“接触对象未确认”的现场证据：整车贴桌干涉已由用户确认，具体触点、外部间距仍未量测。此前只看车头前方空地、未充分检查车尾/侧角及上层部件扫掠，是本轮纠正的问题。

## 尺寸依据与暂定模型

以驱动轴两轮中点为坐标原点，x朝车头、y向左、z向上。区分三类证据：

- **资料尺寸**：PROJECT_STATE中2026-10-20记录标准大号RÅSKOG约45×35×77cm。旧仿真URDF底部碰撞盒约39.13×45.9cm，轮轴相对车体中心x约−15cm，双轮y约±22.5cm；这是旧模型，不能证明当前车就是这个轴心或轮距。
- **现用控制设计值**：whole_calibration采用半径6.35cm、轮距25cm。双轮上游config另有半径5cm默认值；这些来源存在差异，不能用旧URDF静默覆盖实机配置，更不能把轮估累计当真实航向。此次不改任何底盘参数。
- **工程假设**：双臂收起、空爪时，暂取轴心相对x±40cm、y±30cm、z0–150cm的整车外框，容纳轴心偏移不确定性、上层手臂/相机、车架和线缆的规划余量。80×60cm不是实测尺寸，也不是已保证包住全部外垂线缆。另膨胀5cm，完整转身充分圆半径为sqrt(40²+30²)+5=55cm，对应直径110cm；直行参考宽度60+2×5=70cm。二者均只在假设成立时可用，不是通道已验收。

矩形贴墙时，即使起点和终点都能放下，中途的角仍可能先撞墙。算法对四个角随旋转角度的极值求解，包含区间内导数为零的角度；先把整车加余量平移，再计算新轴心处的转身扫掠外接矩形，同时保留整段平移扫掠。外接矩形可保守拒绝部分实际上可行的路线，不能代替完整碰撞模型。

桌面高处的碰撞与椅脚低处同样要算，当前统一投影到地面；看地面空并不能排除桌沿碰到上层手臂、相机、线束或托盘。转身空间按整车轴心与所有边角考虑，不只用轮距/半车宽。先向前让出桌端，是改变障碍与扫掠的相对位置；沿平行桌边前进不自动增加侧向距离，仍要核对桌端是否越过车体后角及整个弧线。

## 现有平台落地

原Studio `/#fieldmap`的“空间观察”中新增“先给整车留位置”，可输入先前进0–50cm、再转−180–180°，查看整车、平移扫掠、旋转扫掠外框和充分空间圆；图示随最大输入自适应缩放。预览输入不是发车或扩展授权。

后端`deployment/fieldmap/body.py`与原应用内接口：

- `GET /api/platform/fieldmap/body`：粗略体态、尺寸来源、假设和未知项。
- `POST /api/platform/fieldmap/body/plan`：`posture:"folded"`、`forward_m`、`turn_deg`，可给同坐标系障碍矩形`obstacles`。返回各阶段外框和已知相交项；没有相交项依然是`clearance_unconfirmed`。不提供定位、不读取相机、不开放运动权限；其他姿态拒绝，而不是默认当已收臂。

三路新图预检16在线、无接管/活动任务，双臂保持收起。先向前3+3+4cm，共10cm请求，三段全完成，轮估合计9.921cm；每段新照片由助手复核后才继续。此后先4、再4、再8个一组分段转向，最终共72个650ms/160脉冲全部完成，没有再次出现上轮轮10滞后停止；右轮编码器正常越过1757附近并回绕。

停车画面从椅子和桌侧逐渐变成过道地面、两侧桌椅，定性支持已转向过道。设计几何的转角明显偏离画面变化，故仍不报精确180°或转角标定通过。车头朝向过道后再前进3+3cm，均完成；本轮五段平移请求共16cm、轮估15.746cm，全部5/5按目标停车，不等于尺量位移或总体成功率。

本轮行进/转向共享快照监看1854条，源帧龄中位56.5ms、最大526ms，无相机故障停止；仅检查图像供应，语义净空由助手段间看图。五段直行共8次温度单读毛刺，立即复读34°C并按既有规则记录，未放宽容忍次数；不能据本次完成就声称毛刺根因已解决。没有提高驱动力、速度/时长上限或改设备参数。

**结论范围**：用户确认、照片和“前移退离后继续转向不再卡住”的实测支持本次贴桌扫掠不足解释。10cm退离、人员/椅子位置变化等并非严格控制实验，不能证明单一因果，也不能推导所有家具旁都先走10cm即可。当前完成的是退离、转向过道与短前进；完整掉头后全程向前返回原点仍未验收，当前没有米制地图/红线围栏或持续无人语义避障。
