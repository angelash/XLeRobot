## 已部署的持续记录

原8770 Studio的空间页增加“看见，也记住”卡片，可查看留存遥测／影像／深度计数，暂停新增记录或保存地图快照。它与手动录制功能分别存储，不妨碍用户继续网页／手柄控制；没有新端口、串口拥有者或开机任务。

- 经原Studio接受的网页控制请求记录完整按键集合、序号、目标手臂、速度及接受结果；会话令牌不入档。控制响应只入有界队列，磁盘写入由后台完成；溢出明确记缺失计数，不宣称永不丢包。
- 每约0.5秒保存原控制服务的编码器、目标、速度、温压、输入状态和驱动来源；按键请求与实测动作分开。物理手柄按轮询状态及原控制事件补充，不能声称每个短按都被精确捕获。
- 运动／人工操控时约每2秒、静止时约每12秒，复用原三路UVC和手机的新帧；没有独立打开相机。照片保留源时刻、序号／会话及SHA；手机RGB-D保存原数组和元信息，并尝试同AR会话累积点云。
- 每15分钟或事件预算到达时分段；重启生成新段，原始样本与照片保留。采样超1.5秒、控制PID变化或轮增量不能保守展开时切断轨迹，不跨缺口猜位移。
- 助手运动的权威轨迹仍来自原agent／servo回执；被动记录作为观察，避免同一次轮位变化重复累计距离。人工操控的轮估轨迹进入原历史时间轴，影像按邻近时间查询。

`/api/platform/fieldmap/journal/status`提供记录与缺口状态；`POST /journal/configure`仅更改新增记录状态，不驱动机器人、不删除旧资料。后台随原Studio生命周期启停。保留总计从落盘记录重算，服务重启不会让历史计数看似清空。
